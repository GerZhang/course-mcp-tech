
# MCP 技术学习项目

本项目是一个学习 Model Context Protocol (MCP) 技术的示例工程，包含了多个演示项目，展示了从基础的 JSON-RPC 通信到完整的 MCP 服务器实现。

## 子项目说明

- **stdio-demo**: 展示基于标准输入输出的进程间通信
- **json-rpc-demo**: 基础的 JSON-RPC 服务器实现，展示基本的 JSON-RPC 2.0 协议通信
- **mcp-demo**: 完整的 MCP (Model Context Protocol) 服务器实现，符合 MCP 标准规范
- **mcp-sdk-demo**: 使用官方 MCP SDK 构建的服务器实现，展示现代化的 MCP 开发方式

## 学习路径

建议按以下顺序学习：

1. **stdio-demo** - 了解进程间通信方式
2. **json-rpc-demo** - 理解 JSON-RPC 2.0 协议基础
3. **mcp-demo** - 掌握完整的 MCP 协议实现
4. **mcp-sdk-demo** - 学习使用官方 SDK 进行 MCP 开发
